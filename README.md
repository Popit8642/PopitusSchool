# 🎓 AI-Методист

Telegram-бот, который готовит конспекты уроков по загруженным PDF-учебникам. Пользователь добавляет учебник, бот разбирает его на смысловые фрагменты, строит векторную базу знаний и по выбранной теме составляет структурированный урок — **только на основе текста учебника**. Всё работает локально, без внешних API.

---

## ✨ Возможности

- 📥 **Загрузка учебников** — пошаговый диалог: название → класс → авторы → PDF. Класс и авторов можно пропустить. Поддерживаются текстовые PDF и сканы (OCR), файлы до 20 МБ.
- ⏳ **Фоновая обработка** — PDF обрабатывается в отдельном arq-воркере. Пользователь сразу видит позицию в очереди, а затем получает уведомление о начале и завершении обработки.
- 📚 **Мои учебники** — список с названием, классом, авторами, статусом, числом страниц и фрагментов. Учебник можно удалить вместе со всеми фрагментами (с подтверждением).
- 🧠 **Генерация уроков** — RAG-поиск по выбранному учебнику и локальная LLM. В конце урока указываются страницы-источники.
- ⚙️ **Выбор нейросети** — в меню можно переключиться между доступными моделями. Free-пользователям доступна базовая модель, Pro — обе.
- 💎 **Покупка Pro** — оплата подписки через Telegram Stars прямо в боте; после оплаты тариф активируется автоматически.
- 📞 **Контакты** — текст с контактами поддержки (пока заглушка).
- 👑 **Подписки Free/Pro** — админ выдаёт и снимает Pro по Telegram ID или `@username`; пользователь получает уведомление.
- 👤 **Изоляция данных** — у каждого пользователя свои учебники и уроки.
- 🛡️ **Надёжность** — таймауты LLM, ограничение параллельных запросов к Ollama, plain-text fallback при ошибке HTML-разметки, разбивка длинных сообщений, восстановление незавершённых задач после перезапуска воркера.
- 🧑‍💼 **Админ-панель** — статистика, рассылка, управление нейросетями и подписками.
- 🪵 **Логирование** — ключевые этапы (загрузка, очередь, ingest, RAG, генерация, ошибки) пишутся в консоль.

## 🏗️ Архитектура

```
┌─────────────┐     ┌──────────┐     ┌─────────────┐
│  Telegram   │────▶│  Redis   │────▶│   Worker    │
│    Bot      │     │ (arq)    │     │   (arq)     │
└──────┬──────┘     └──────────┘     └──────┬──────┘
       │                                     │
       │              ┌──────────────┐       │
       └─────────────▶│  PostgreSQL  │◀──────┘
                      │  + pgvector  │
                      └──────┬───────┘
                             │
                      ┌──────▼───────┐
                      │    Ollama    │
                      │ LLM + embed  │
                      └──────────────┘
```

1. **Bot** — принимает PDF, создаёт запись учебника со статусом `pending`, ставит задачу в Redis и отвечает пользователю.
2. **Worker** — парсит PDF (текстовый слой + OCR), считает эмбеддинги батчами и сохраняет чанки в PostgreSQL.
3. **PostgreSQL + pgvector** — хранит пользователей, учебники, чанки, историю уроков и аудит рассылок.
4. **Ollama** — локальная LLM для генерации урока и модель эмбеддингов для поиска.

## 🚀 Запуск

### 1. Требования

- Python 3.11+
- PostgreSQL 16 с расширением `pgvector`
- Redis
- [Ollama](https://ollama.com)
- Tesseract OCR с русским языком (для сканов)

```bash
sudo apt install postgresql-16-pgvector redis-server \
                 tesseract-ocr tesseract-ocr-rus poppler-utils
```

### 2. Клонирование и зависимости

```bash
git clone https://github.com/Popit8642/PopitusSchool.git
cd PopitusSchool
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Модели в Ollama

```bash
ollama pull qwen2.5:3b-instruct-q4_K_M   # базовая модель (Free)
ollama pull qwen3:4b-instruct-2507-q4_K_M  # модель Pro
ollama pull embeddinggemma                 # эмбеддинги
```

> На слабом железе генерация урока на 3B-модели занимает около минуты, на 4B — 1–2 минуты. Таймаут по умолчанию — 240 секунд, одновременные запросы к Ollama ограничены (`LLM_MAX_CONCURRENCY=1`).

### 4. Настройка окружения

Создайте `bot/.env` по образцу [`bot/.env.example`](bot/.env.example):

```env
BOT_TOKEN=your_telegram_bot_token
PROXY_URL=

DB_HOST=localhost
DB_PORT=5432
DB_USER=popit
DB_PASS=your_db_password
DB_NAME=PopitusSchool

REDIS_URL=redis://localhost:6379

LLM_BASE_URL=http://localhost:11434
LLM_MODEL_CHAT=qwen2.5:3b-instruct-q4_K_M
LLM_TIMEOUT_SECONDS=240
LLM_MAX_TOKENS=3000
LLM_MAX_CONCURRENCY=1

EMBEDDING_BASE_URL=http://localhost:11434
EMBEDDING_MODEL=embeddinggemma
EMBEDDING_DIM=768

RAG_TOP_K=5
RAG_MAX_DISTANCE=0.7

MAX_PDF_SIZE_MB=20
MIN_PDF_SIZE_KB=10
OCR_LANG=rus+eng
UPLOAD_DIR=data/uploads

MODERATION_MODEL=qwen2.5:3b-instruct-q4_K_M
MODERATION_TIMEOUT_SECONDS=60
MODERATION_MAX_CHARS=2000

ADMIN_IDS=
```

### 5. База данных

```bash
# создай пользователя и БД (один раз)
sudo -u postgres psql -c "CREATE USER popit WITH PASSWORD 'your_db_password' SUPERUSER;"
sudo -u postgres psql -c 'CREATE DATABASE "PopitusSchool" OWNER popit;'

# примени миграции
.venv/bin/alembic upgrade head
```

Схема меняется **только через Alembic**. Не используйте `create_all()` в продакшене.

### 6. Запуск

Нужно **два процесса** в разных терминалах:

```bash
# Терминал 1 — бот
cd bot
../.venv/bin/python main.py

# Терминал 2 — воркер
cd bot
../.venv/bin/arq worker.WorkerSettings
```

## 📱 Использование

Главное меню — reply-клавиатура. У Free-пользователей есть кнопка «💎 Купить Pro», у Pro она скрыта:

- **📚 Мои учебники** — список учебников, статусы и удаление.
- **➕ Добавить учебник** — название → класс (можно пропустить) → авторы (можно пропустить) → PDF.
- **🧠 Сгенерировать урок** — выбрать готовый учебник → ввести тему → получить конспект.
- **💎 Купить Pro** — оплата подписки через Telegram Stars (только для Free).
- **📞 Контакты** — контакты поддержки и информация об оплате.
- **⚙️ Выбрать нейросеть** — посмотреть свою подписку и переключить модель.
- **❓ Помощь** — краткая инструкция.

### Фильтрация нежелательного контента

Загрузка PDF проходит две проверки:

1. **Быстрые проверки в боте** (до скачивания/создания документа):
   - имя файла с нежелательными словами (`porno`, `sex`, `xxx`, `nudes`, `голые`, `18+` и т.п.) → «❌ Файл заблокирован системой безопасности»;
   - файл меньше `MIN_PDF_SIZE_KB` (по умолчанию 10 КБ) → отклоняется как пустышка или мусор.
2. **LLM-модерация в воркере** (после извлечения текста/OCR, до эмбеддингов):
   - первые 3–5 чанков (не больше `MODERATION_MAX_CHARS` символов) отправляются лёгкой модели `MODERATION_MODEL`;
   - если модель отвечает «БЛОК», документ и его чанки удаляются из БД, временный файл удаляется, пользователь получает «❌ Загрузка отклонена…»;
   - PDF без распознаваемого текста отклоняется так же;
   - при ошибке или таймауте модерации действует fail-open: документ обрабатывается дальше, воркер не падает.

### Нейросети и подписки

Модели хранятся в таблице `ai_models` и управляются из админки. У каждой модели есть:

- `name` — отображаемое имя (например, `PopitusGPT1.0v`);
- `ollama_tag` — реальный тег в Ollama;
- `required_tier` — `free` или `pro`;
- `is_active` — доступна ли модель;
- `is_default` — модель по умолчанию, если пользователь ничего не выбрал.

Как бот выбирает модель при генерации:

1. явный выбор пользователя, если модель активна и разрешена его тарифу;
2. модель по умолчанию его тарифа (для Pro — Pro-модель, для Free — базовая);
3. любая активная модель тарифа;
4. `LLM_MODEL_CHAT` из `.env` как аварийный fallback.

Пользователь видит только доступные ему модели: Free — базовую, Pro — обе. Выбор сохраняется в `users.selected_model_id`. При выдаче Pro пользователь автоматически переключается на Pro-модель, если у него была выбрана базовая; при снятии Pro выбор Pro-модели сбрасывается.

### Оплата Pro через Telegram Stars

- Free-пользователь нажимает «💎 Купить Pro» (в главном меню или на экране выбора нейросети) и получает счёт в Telegram Stars (валюта `XTR`, цена — `PRO_PRICE_STARS`, по умолчанию 100).
- `pre_checkout_query` подтверждается автоматически, иначе Telegram отменит платёж.
- После `successful_payment` пользователю выставляется `subscription_tier = pro`, он получает уведомление и автоматически переключается на Pro-модель.
- Повторная оплата при уже активном Pro не меняет тариф: бот вежливо сообщает, что подписка уже действует.
- Админы из `ADMIN_IDS` получают уведомление о каждой покупке.
- Для тестирования Stars используйте тестовые платежи (`@PremiumBot` / тестовые Stars); реальные списания при этом не происходят.

### Статусы учебника

| Статус | Что означает |
|--------|--------------|
| `⏳ В очереди` | Задача создана и ждёт воркер |
| `⚙️ Обрабатывается` | PDF разбирается, считаются эмбеддинги |
| `✅ Готов` | Учебник можно использовать для уроков |
| `❌ Ошибка` | PDF повреждён, пуст или не распознан |

### Очередь

После отправки PDF бот отвечает: «📥 Файл принят. В очереди: позиция N». Когда воркер берёт задачу, сообщение меняется на «⏳ Начинаю обрабатывать…», затем на результат. Если бот или воркер перезапустился, незавершённые задачи восстанавливаются из БД.

## 🧑‍💼 Админ-панель

Доступ только пользователям с флагом `users.is_admin`:

```bash
/admin_panel
```

Возможности:

- 📊 **Статистика** — пользователи, Pro-подписки, активные получатели рассылки, учебники, готовые учебники, фрагменты, сгенерированные уроки, размер очереди.
- 🧠 **Нейросети** — список моделей с тегами и тарифами; включение/выключение и назначение модели по умолчанию (⭐).
- 👑 **Подписки** — выдача и снятие Pro по Telegram ID или `@username`. Пользователю уходит уведомление; если он заблокировал бота, админ увидит это в отчёте.
- 📢 **Рассылка** — предпросмотр, подтверждение, пауза между сообщениями, обработка блокировок и `RetryAfter`, аудит в таблице `broadcasts`.

Нельзя выключить модель по умолчанию или единственную активную Free-модель — сначала назначьте другую.

Флаг администратора выдаётся:

- автоматически при старте бота для ID из `ADMIN_IDS` (через запятую);
- вручную в БД: `UPDATE users SET is_admin = true WHERE telegram_id = ...;`.

Повторная рассылка ограничена `BROADCAST_COOLDOWN_SECONDS` (по умолчанию 60 секунд).

## 🗄️ Миграции

```bash
.venv/bin/alembic current        # текущая ревизия
.venv/bin/alembic upgrade head   # применить все миграции
.venv/bin/alembic downgrade -1   # откатить последнюю

```

Перед миграциями в продакшене делайте дамп:

```bash
pg_dump -Fc -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f data/backups/backup_$(date +%Y%m%d_%H%M%S).dump
```

## ⚠️ Ограничения

- Telegram Bot API отдаёт ботам файлы до **20 МБ**. Для больших PDF нужен [локальный Bot API server](https://github.com/tdlib/telegram-bot-api).
- Качество уроков зависит от модели. На 3B-модели возможны неточности; для лучшего результата используйте 14B и выше.
- OCR сканов работает, но качество зависит от исходного изображения.
- Один воркер обрабатывает один документ за раз (`max_jobs = 1`), чтобы не перегружать Ollama.
